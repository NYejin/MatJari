# 구역 모양 학습 v2 (RF-DETR Seg Nano) 결과

좌석표 도형(구역 모양)을 찾는 작은 모델을 학습해 현재 파이프라인과 비교한 기록이다. 원자료는 저장소 밖 `eval-data/report/train_v2_record.md`(2026-11-04~05, 접근일 2026-11-06), 결과 페이지는 https://claude.ai/artifact/MeQpn8728fcxt9XQ4VGbwj 다. 운영 파이프라인 자체는 [AI 회차·구역 읽기 설계 근거](../decisions/ai-detail-extract-design.md)와 CLAUDE.md 'AI 회차·구역 읽기' 절이 기준이다.

## 1. 평가셋과 누출 점검

- 평가셋은 멜론 정답 지도 38장·741구역(판정 IoU 0.5 이상 + 이름 일치)이며 바꾸지 않았다.
- 점검 방법: 상품 번호, 원본 이미지 주소(변환 꼬리 제거), 좌석표 이미지 SHA-256, 지각 해시(pHash·dHash), ORB 특징점 + RANSAC. 후보 1,006장 x 정답 38장.
- 결과: 번호·주소·SHA 겹침 0건, ORB로 사실상 같은 지도 6장(모두 정답과 같은 공연장). 같은 배치 재사용까지 막으려고 **정답 38장의 공연장에서 나온 지도는 학습에서 모두 뺐다**(123장). 이름 집합 유사도(Jaccard)는 A·B·C 같은 흔한 이름 때문에 판정에 쓰지 않았다.

## 2. 데이터 단계별 장수

| 단계 | 장수 |
|---|---|
| 멜론 상품 페이지 수집(번호 201000~214599, 공개 HTML) | 13,600 |
| 상세 이미지 있는 후보 / Haiku에 물어본 것 | 11,783 / 10,576 |
| "구역 블록 지도"라고 답한 것 | 1,449 |
| 답한 구역 수 5 이상(가짜 정답 생성) | 1,055 |
| 파이프라인이 모양 있는 구역 5개 이상 만든 것 | 411 |
| 모양 있는 구역이 이름의 70% 이상 | 368 |
| 정답 공연장 제외 후 최종 | **245** (학습 220 / 조기종료 검증 25) |

- **라벨은 전부 자동 생성**이다. 당시 운영 파이프라인(master 05c1396, Haiku 5.5)의 출력 다각형을 그대로 썼고 **사람 검수는 0%**다. 평가셋 기준 라벨 조각 재현율 85.6~86.6%, 정밀도 93.5~94.5%.
- 인터파크(NOL) 좌석표 70장은 라벨을 만들지 않아 넣지 않았다(추가 비용 없이 지금 데이터로 학습하기로 한 사용자 결정).

## 3. 학습 설정과 시간

- RF-DETR Seg Nano(Apache 2.0), 입력 384px, batch 1 x grad accum 8, lr 2e-4, EMA, 최대 20 epoch, 조기 종료 patience 4.
- 순서: 가짜 정답 사전학습 -> 5겹 미세조정(겹마다 정답 30~32장, 시험 겹 정답은 모델 선택에 쓰지 않음).
- 장비 GTX 960(2GB) 로컬 PC, 클라우드 비용 0원. 사전학습 9시간 52분(최고 EMA mAP 0.323), 미세조정 겹당 약 1시간, 예측 지도당 약 1.3초.
- 사고(대기열 중복 실행으로 체크포인트가 섞임)는 [학습 실행 함정](../gotchas/training-run-pitfalls.md) 참고.

## 4. 평가 (정답 38장, 새 AI 응답 3표본 평균)

| | 재현율 | 정밀도 | F1 | IoU 0.8 이상 |
|---|---|---|---|---|
| B 현재 파이프라인 | 93.6% | 97.0% | 95.2% | 81.9% |
| C 학습 도형 추가(v2) | 95.2% | 97.3% | 96.3% | 83.6% |

- 재현율 증가(+12.3구역) 중 +10구역이 213216 한 장이다. 뺀 나머지는 +2.3구역(+0.3%p). 모양 틀림은 21.3 -> 23.0으로 조금 늘었다.
- 이 결과의 해석과 운영 반영 여부는 [결정 페이지](../decisions/learned-shape-gap-fill.md).

## 한계

- 평가셋이 38장·한 사이트(멜론)뿐이고 라벨이 자동이라 모델 한계가 라벨 품질(재현율 약 86%)에 묶인다.
- 원자료 수치를 옮긴 것이라 재현은 하지 않았다(confidence medium).
